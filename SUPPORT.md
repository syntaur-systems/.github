# Support

If you need help with Syntaur:

- **Documentation:** project README and [syntaur.app](https://syntaur.app)
- **Bug reports:** open an issue against the appropriate repo (see [CONTRIBUTING.md](https://github.com/syntaur-systems/syntaur/blob/main/CONTRIBUTING.md))
- **Security issues:** email `security@syntaur.app` (see [SECURITY.md](https://github.com/syntaur-systems/syntaur/blob/main/SECURITY.md) — do not open public issues for security reports)
- **Partnership inquiries:** email `partnerships@syntaur.app`
- **General contact:** email `hello@syntaur.app`

We respond to email within a few business days; security reports get priority and an acknowledgement within 72 hours.
